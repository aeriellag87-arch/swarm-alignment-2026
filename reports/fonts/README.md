# Fonts

The Featherlight faces: the exact files the original app's Featherlight plates are minted from, decoded from
`src/lib/featherlight/faces/*.ts` in the original codebase, each checked against the sha256 recorded there.

- `featherlight-serif-*.ttf`: Spectral (Latin subset). Copyright 2017 The Spectral Project Authors
  (https://github.com/productiontype/Spectral). SIL Open Font License 1.1.
- `featherlight-mono-*.ttf`: IBM Plex Mono (Latin subset). Copyright 2017 IBM Corp. SIL Open Font License 1.1.

The licence text is at https://openfontlicense.org.
